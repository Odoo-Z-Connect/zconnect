# ZConnect Odoo Repository

Welcome to the ZConnect backend repository. This repository contains all the custom Odoo modules that power the ZConnect logistics and parcel delivery platform in Zimbabwe.

## Documentation
A comprehensive, 20+ page technical documentation package has been generated for this project. It covers the architecture, data models, workflows, API, and deployment guidelines.

**👉 [Start Reading the Documentation Here](docs/README.md)**

## Postman Collection
For mobile app developers, a fully documented Postman collection for the `zconnect_api` is available:
**👉 [Download ZConnect API Postman Collection](docs/ZConnect_API_Postman_Collection.json)**

## Supported Odoo Version
- **Odoo 19 Enterprise**
- PostgreSQL 16

## Quick Start
1. Add this repository to your Odoo `addons-path`.
2. Update the module list.
3. Install the `zconnect_portal` and `zconnect_dashboard` modules to pull in all dependencies.
